# Brew & Bean ☕

A one-page website for a small neighbourhood coffee shop, built with HTML, CSS and JavaScript.

**Live site:** https://abhinavrenjithg-sys.github.io/Brew-Bean/

## Features
- Sticky navigation bar with smooth scrolling
- Hero section with an arch-shaped photo
- Menu cards with prices
- About and contact sections
- Responsive layout with a ☰ mobile menu (below 760px)
- Footer year filled in automatically with JavaScript

## Tech used
- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- JavaScript
- Google Fonts (Playfair Display, DM Sans)
- Photos from Unsplash

## Files
| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `src/style.css` | Design and responsive layout |
| `src/script.js` | Mobile menu and footer year |

## Run locally
Open `index.html` in any browser.
